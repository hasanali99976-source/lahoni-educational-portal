# V2 Acceptance Gate

لا تنتقل V2 إلى Production قبل اجتياز الآتي:

- [ ] Build ناجح بلا أخطاء.
- [ ] الصفحة الرئيسية وتسجيل الدخول بهوية V2 فقط.
- [ ] الإدارة والمعلم والطالب وولي الأمر على نفس Design System.
- [ ] جلسة المعلم 10 أيام.
- [ ] جلسة الطالب 10 أيام.
- [ ] الإدارة هي المصدر الرسمي لقائمة الطلاب والفصول.
- [ ] إضافة/تعديل/نقل طالب يظهر للمعلم دون إنشاء طالب مكرر.
- [ ] نقل الطالب لا يحذف تاريخه السابق.
- [ ] العدد في لوحة المعلم يطابق القائمة الرسمية للفصول المصرح بها.
- [ ] الجدول يلتزم بالفصول التي حددتها الإدارة للمعلم.
- [ ] الحضور معزول حسب المعلم والمادة والصف والفصل والتاريخ والحصة.
- [ ] التحضير معزول حسب المعلم والمادة والصف والفصل والتاريخ والحصة.
- [ ] الدرجات مرتبطة بالطالب الصحيح والفصل الصحيح.
- [ ] ما ينشر للطالب يظهر في حساب الطالب الصحيح فقط.
- [ ] نفس البيانات تظهر على الكمبيوتر والجوال/التطبيق بعد إعادة التحقق من الخادم.
- [ ] لا polling دوري لبيانات Firestore.
- [ ] لا retry loops مستمرة.
- [ ] لا write عند عدم تغير القيمة.
- [ ] لا backfill تلقائي عند فتح الصفحات.
- [ ] مراجعة runtime logs وعدم وجود حلقات RESOURCE_EXHAUSTED.
- [ ] اختبار فصلين للمعلم في نفس اليوم والحصة وعدم اختلاط الحضور أو التحضير أو الدرجات.
- [ ] Preview ناجح قبل أي دمج إلى main.
- [ ] Production يتم تغييره بعد التحقق فقط، مع بقاء آخر نسخة مستقرة كمرجع رجوع.
